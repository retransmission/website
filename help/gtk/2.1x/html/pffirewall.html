Configuring the firewall

Ubuntu 8.04 comes with the ufw firewall installed by default.

  • For instructions on how to use it, open a Terminal and type 'man ufw'.
  • You need to ensure that Retransmission's port (displayed in Preferences) is opened in the firewall.
